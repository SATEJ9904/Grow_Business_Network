## Utility Classes

### Flexbox
- `.flex` - Display flex
- `.flex-row` - Row direction
- `.flex-col` - Column direction
- `.items-center` - Center items vertically
- `.justify-center` - Center content horizontally
- `.justify-between` - Space between
- `.gap-1`, `.gap-2`, `.gap-3`, `.gap-4` - Gap sizes

### Spacing
- `.m-1` to `.m-8` - Margins (4px to 32px)
- `.p-1` to `.p-8` - Padding (4px to 32px)
- `.mt-1` to `.mt-6` - Margin top
- `.mb-1` to `.mb-6` - Margin bottom
- `.px-2` to `.px-4` - Horizontal padding
- `.py-2` to `.py-4` - Vertical padding

### Text
- `.text-xs`, `.text-sm`, `.text-base`, `.text-lg` - Font sizes
- `.font-normal` to `.font-extrabold` - Font weights
- `.text-center`, `.text-left`, `.text-right` - Text alignment
- `.text-primary`, `.text-secondary`, `.text-tertiary` - Text colors
- `.uppercase` - Uppercase text
- `.truncate` - Text truncation
- `.line-clamp-1`, `.line-clamp-2` - Multi-line clamping

### Colors
- `.bg-primary`, `.bg-secondary` - Background colors
- `.text-success`, `.text-danger` - Text colors
- `.bg-success`, `.bg-danger` - Background colors

### Display
- `.hidden` - Hide element
- `.block` - Block display
- `.inline-block` - Inline-block display
- `.flex` - Flex display
- `.grid` - Grid display

### Other
- `.cursor-pointer` - Pointer cursor
- `.opacity-50` - 50% opacity
- `.transition-fast` - Fast transitions
- `.transition-base` - Normal transitions
- `.hover-lift` - Lift on hover animation
- `.shadow-sm` to `.shadow-xl` - Shadow levels

## Animation Classes
